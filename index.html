Begin a life in Beastbound

Start as an ordinary person. Build a profession, cultivate your own power, negotiate with beasts—or never bond with one. Your choices change the ledger.

The game is offline and deterministic. Autosave uses this browser; export a JSON file to keep a portable save. Project chat play uses the companion project instructions.

Beastbound master canon is authoritative. This is a working prototype, not a simulation of every species or civilisation.

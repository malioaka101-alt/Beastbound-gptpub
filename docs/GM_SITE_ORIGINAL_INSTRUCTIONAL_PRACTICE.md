# Original independent education work → original individual learner practice

This is a narrow source-backed connection between **already implemented** group-site member work (`world/emergent-groups.js`, `rules/group-invitations.js`), individually witnessed GM professional duties (`world/person-careers.js`) and the player's existing professional mastery check (`rules/mastery-lifepath.js`). It is **not** another school, academy, tutor, skill or staffing system.

## Source and operation

`social.studyWitnessedGroupMethod({groupId, serviceId, skill, focus, minutes?})` permits the player/founder to independently practise **one ordinary professional skill** after an originally completed, independently successful `social.observeGroupRoleWork` for a voluntarily accepted member at the **same established physical site**, on the same day. The original GM-authored duty must explicitly be educational and instructional; its actual working method must be the player's existing skill. Before use, the original source record, role consent, member identity, career receipt, site and world time are checked.

The **original `Lifepath.practice`** alone determines one learner d20, actual stamina/time and earned practice. The group retains an attested reference to the original training event and its source hash so the short mastery journal can rotate without erasing that the observed work informed this student's session. Inspecting `social.groupRoleWorkStatus` is read-only.

The teacher's prior independently executed work is **not rolled again**, does not guarantee attendance at every subsequent lesson, and does not select the student's result. If an original worker refuses, fails, is not physically witnessed or did not perform a teaching method, there is no supported work evidence to copy.

## Deliberate boundaries

- No extra student XP, novel skill rank, cultivation stage, supernatural technique or licence is awarded from the teacher's profession or academy name.
- No additional tuition payment, wage, school ownership, employment contract or institutional status is inferred. Original source owners must verify any such event separately.
- This single ordinary-practice bridge does **not** claim to implement every educational program, diploma, specialised teacher technique, off-site lecture or arbitrary method. Such cases are new opportunities to connect to the existing owner when actually established.
- GM-authored groups can have innumerable histories, customs and practices without source-running an unnecessary mechanical lesson for ordinary dialogue.

`tests/gm-site-original-professional-study.test.js` uses only a disposable scenario with real member consent, one independent career receipt and one original player mastery check. Historical roles and records survive round-tripping, and repeated attribution is rejected. **No campaign save is touched.**

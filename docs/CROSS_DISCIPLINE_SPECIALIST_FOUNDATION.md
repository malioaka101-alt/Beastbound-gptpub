# Foundation #16 — Cross-discipline compatibility and specialist arts (draft)

Authority: **original Unified Master Prompt §§19, 26, 29**. Unlike a universal rank ladder, Meridian anatomy, Arcane Mana Core matrices, Soul identity, living Body tissues, Beast-Origin material, Rift physics and distinct specialist crafts develop independently. A hybrid can be feasible, helpful, unstable or harmful depending on an individual's real capacities and independent observations. This foundation must not create a second universal energy reservoir, auto-copy techniques, auto-award mastery, force a teacher/tuition fee or say a character can never learn a viable individual method without a prewritten menu.

## First observed interaction: an individual's original Meridian–Arcane circulation test

The narrow initial `rules/cross-discipline-coherence.js` adapter connects **the already genuine first Lower Meridian Gate** (`rules/meridian-qi-strike.js::gate`, requiring original anatomical source records) and **the already genuine First Arcane Circle** (`rules/arcane-spark.js::curriculum`, requiring its source-dated learned Core/Circle). Merely possessing Qi and Mana or editing a stage number does not establish these. A real GM independent scene observation must report the specific existing Gate, actual individual Circle geometry, existing tissue/Qi route, Mana Core output route, **separate Qi-only and Mana-only baselines**, measured personal observed phase response and an independent reversal/countertest with heat, metabolic supply, recovery and pressure failure.

`cross.qiManaExperiment` accepts only the prior witnessed event index and derives the original difficulty from actual Gate quality, existing Core stability, independent measured interaction and accumulated individual strain. Exactly **one original engine d20** decides a bounded physical calibration. The first observed example costs **3 existing Qi, 3 existing Mana, 2 actual Stamina and 30 real world minutes**, including on unsuccessful trials, and can cause an actual wound and accumulated circulation strain on severe failure. A successful, independently observed `coherent` interaction creates a **60-minute original locally observed coherent Qi/Mana field**. `interfering` or `unsafe` findings never magically transform into a coherent effect merely because a check succeeded. The field is a **measured transitory physical state**, not a learned spell or a rule-exempt +X to every action; any effect on an existing Ward, Formation, weapon art or spell requires a separately source-supported adapter. A read-only `cross.qiManaStatus` lists actually observed fields and strain without reading thoughts or asserting secrets.

The first documented costs, interaction categories and temporary field are **initial measured examples**, not universal values, a compulsory school, a fixed list of hybrid combinations or an inference that all meridians share the same Mana compatibility. New biological routes, Soul/Arcane couplings, Body/Meridian support, Origin conflict, Rift/formations, runic libraries, alchemy, weapon intent and healing interfaces need their own witnessed physical/cultural sources, interoperable original resource ledgers, actual effects, consent where relevant and independent countertests. Specialists can excel professionally without a corresponding combat tier.

`tests/cross-discipline-qi-mana-coherence.test.js` covers genuinely source-recorded prior Gate/Circle fixture, original Qi/Mana/Stamina costs, real one-roll checks, individual interference modes, refusal of selected guaranteed result/bonus, tamper rejection, source persistence through log rollover and expiration. The test is **first** in the full engine regression list. **#16 remains unchecked** until this and later expandable cross-disciplinary applications are accepted; the first slice is draft and no active campaign saves changed.

# Foundation #13 — Living human Body IV–VII and open individual physiques

**Original authority:** Unified Master Prompt §§23 and 28–30, plus the existing first three earned body cycles and real wounds/physiological history. Body Refinement changes an actual person's anatomy. It is **not** a generic character rank, new beast type, Meridian tier, Arcane Circle, or automatically purchased trait.

## Implemented draft: source-backed human tissue IV–VII

`rules/body-living-refinement.js` records GM-authored original bodily histories at `s.table.bodyRefinement.cycles` using the **existing** `s.player.body.cycles` (Muscle–Tendon, Bone–Marrow and Organ Cycle) and the same canonical player/combatant Stamina. The prerequisite is truly earned Cycle III Organ integration with source-hashed original prior practice and earlier successful histories, not a claimed label.

Each new body-cycle design identifies the **personally observed actual tissues**, functioning physiology, energy/nutritional needs, failure limits and plausible reversion circumstances. Merely naming an organ, supernatural bloodline or an imaginary resistance does not create those tissues. A separately witnessed real source anchors the design; an independently measured physiological response supports each actual training check; an independent whole-body countertest establishes the final earned transformation. Training, failure, repair and breakthrough each spend **Stamina and world time** through the actual engine. Severe failure can inflict a real existing-model wound and permanent-to-source structural strain. Clinical source-witnessed care reduces real recorded strain only after its own paid successful check.

- **IV — Nerve–Sense:** personally measured original nerves, proprioception, pain and sensation, with known signal failures.
- **V — Blood–Essence:** actual circulatory and hematologic adaptation, tissue oxygenation, thermal and nutritional limits, without an automatic supernatural lineage.
- **VI — Adaptive Physique:** an observed bounded reversible environmental and tissue response, with real conditions, expenditure and a safe return requirement.
- **VII — Evolved Physique:** one uniquely integrated individual constitution based on genuinely functional nerve, blood and adaptive systems, documented upkeep and existing vulnerability. Does **not** automatically award a new species, extra life, invulnerability, resurrection or a free evolution rank.

**Training order freedom:** the underlying Master Prompt explicitly allows schools to specialise and to complete cycles in different orders. Once actual whole-body Organ Cycle anatomy exists, IV–VI can be learned in any compatible individual order; Cycle VII integration needs them functioning together. The engine records the actual order and sources, not a universal taught-course curriculum, prescribed biography or compulsory fee.

The current baseline awards modest verified physical Stamina capacity from each successful bodily integration while **not refilling current Stamina**, changing Qi, Soul, Mana, human evolution stage, lineage or automatically activating unverified combat/medicine. Any distinct sensory ability, specific resistance, medical procedure, physiological compensation, human lineage mutation or environmentally altered combat effect will need its own physical source, limits, relevant resolver and actual outcome. This is not an excuse to deny creative bodily techniques: it distinguishes origin and capability from a named yet unproven effect.

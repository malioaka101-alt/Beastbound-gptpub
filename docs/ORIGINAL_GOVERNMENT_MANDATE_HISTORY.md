# Foundation #18 — original constitutional mandate continuity (fifth draft slice)

The original Unified Master Prompt §§33–36 expects political institutions to have distinct histories, laws, succession, disputes, accountability and public institutions. This **does not authorize creating royalty, overturning a dynasty, choosing an officeholder, spending public money or replacing original political evolution by assistant decree**. The existing 24 government charters and original world monthly `Gov.transition` already implement independent non-hereditary civic mandates; hereditary courts remain separately safeguarded.

This in-place addition extends **`world/government-offices.js`**, not a second political engine. Each original office retains the original initial public holder, authentic existing charter/constitutional selection style, actual independent world decision values already drawn when a government transition really occurs, original region's stability/legitimacy and named household influence considered, the previous and following authentic office holder, original mandate number and date. The complete individual `mandateHistory` is kept **on that exact existing government office** with a sealed source, reconstructable selection formula and contiguous holder/mandate chain. Short `recentPublic` announcements can still rotate; the original historic mandate evidence does not disappear with them. `historicMandates(w,id)` returns an independently verifiable source-backed public succession/renewal record rather than conjectured ancient history. Nothing about an office's own original selection law, candidates, actual world RNG, taxes, trade routes or government treasury is changed.

A crucial safe migration distinction: **old historical campaign saves did not retain individual past ballots or identities**. For an earlier save, `Gov.ensure` may start a truthful *current-day audit anchor* from the actual already known saved holder and mandate number, with an explicit note that preceding selections are **not known**. It does NOT fabricate missing older officeholders, winners, voting history or heirs. A new genuine transition after the anchor appends exact original source evidence. Existing unrelated government office records and active game saves remain unchanged in the repository until play uses the updated engine.

A disposable `tests/public-office-mandate-provenance.test.js` uses a real original existing nonhereditary polity and its actual government transition function with deterministic independent original decision inputs, verifying normal renewal versus contested successor, actual original draw counts, no extra player/world RNG, original public officeholder and cross-world treasury untouched, no forged hereditary succession, save/export/import, evidence rejection on tampering, and safe migration of an earlier current-holder-only record. This adds **one full regression group** to the current accepted #59 inventory, initially 178 on the PR branch. When pending clean-head [PR #60](https://github.com/malioaka101-alt/Beastbound-gptpub/pull/60) merges, this draft needs a clean main-based reparenting with a **179-group complete exact-head CI**, then can be considered for acceptance.

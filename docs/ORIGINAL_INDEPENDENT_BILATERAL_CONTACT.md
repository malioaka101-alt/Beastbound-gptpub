# Foundation #18 — actual independent bilateral willingness, no invented treaty

**Authority:** Original Beastbound Unified Master Prompt §§33–36: living, independent and often disagreeing organisations, kingdom foreign policy, trade-route disruption, legal boundaries and real negotiated obligations. These source rules do NOT imply universal factions, fixed political alignments, obligatory contacts, or mandatory payment/rank menus. GM narrative is open-ended; only explicitly source-backed outcomes become mechanical truth.

## A consequential world problem, two separate autonomous decisions

The original `world/simulation.js` already makes its existing original month political/commerce decisions. A real atlas-connected trade corridor can genuinely become **disrupted**, through original weather and/or war pressure, and the original trade-route ledger now preserves the actual weather/flow/route status as witnessed in fully verified PR #73. The original diplomacy pair already keeps actual source-sealed historic relations and both true historical government officeholders from PR #72.

This draft connects those **same original objects**, not another economy or another fake country. During the existing original month tick, *after* real route/weather effects, government mandates and international relations are resolved, a relation pair with an actually interrupted shared route may consider **one genuine exploratory contact about that actual disruption**. Eligibility requires the existing same-route original `originalChanges` closure source, its valid source hash, current route still interrupted, and an event no older than 60 genuine world days; each original closure may prompt at most one approach. No optional role, nationality or interest is automatically assigned to the player.

**Both existing government institutions independently decide.** The model uses the real historical offices on both sides, actual country stability/legitimacy and the real current diplomatic relationship to set separate bounded chances. It draws ONE actual separate random willingness choice for each government. These are actual **new political-agency choices** (unlike older provenance-only work), intentionally isolated in a reproducible per-pair world political choice stream, source-sealed and replayable. The ordinary original player dice and pre-existing world/route/ecology/market RNG and outcomes remain unaffected. There is no way for the player to set the chance or select either government's answer. Either government can refuse, including when the other wishes to talk; neither refusal nor mutual willingness is guaranteed.

The existing `w.diplomacy[pair]` now optionally holds `contactAttempts` plus `contactRngState` for this **same original pair**. `verifyBilateralContacts(w,key)` replays each independent actual sovereign-level agency draw from a world-seeded pair anchor, checks both pre-existing government officeholders and original historical mandate hashes, checks each genuine prior route-closure source and historical international status, prevents repeated usage of one closed corridor event, and rejects rewritten historical answers. Genuine old saves without any contact evidence remain unchanged; no earlier imagined minister, meetings, treaties or foreign refusals are reconstructed.

## Strong nonclaims

Willingness by two governments means only **institutional willingness to explore contact**. It is NOT proof that a specific minister, travelling envoy, official court, beast polity representative or resident personally consented, nor that someone physically met, agreed terms, signed a treaty, received an appointment, changed laws, transferred property, granted corridor access or reopened a route. Even mutual interest leaves the **original existing** trade and diplomacy state unchanged. This is a first step toward possible diplomacy, NOT a full negotiation/contract engine. The current issue is organically sourced from a real existing disrupted corridor, not a hardcoded dialogue menu or compulsory route.

Only actual **mutual willingness** may generate an original international courier bulletin, using the existing **14-day** foreign-release delay. A unilateral refusal stays private to the underlying world: players must not be given an omniscient list of which foreign government declined. A future real direct conversation might provide other facts, but this code does not invent or perform that conversation.

The existing read-only chat-turn contract gains `world.bilateralContactHistory({pairKey})`, restricted to the actual local polity of one original pair. It shows only already released public mutual-contact bulletins, not prior concealed refusals, private rolls, government stability, signed terms, actual meeting claims, hidden foreign routes or any new resources. Its published original source survives rotation of shorter news buffers. Older saves without contact history return an honestly empty published history.
